# QMG Studio Gallery

Community boot / shutdown animations for [QMG Studio](https://github.com/xBooM-SL/Qmg-studio).

## Add yours
1. In QMG Studio open the **Gallery** tab and tap **Share my animation**.
2. This page opens on `items/`. Tap **Add file → Upload files** and choose the `.zip` and the `.jpg` that the app saved in `QmgStudio`.
3. Send the change (GitHub makes a pull request). After it is approved, everybody sees it in the app.

File names: `name_WIDTHxHEIGHT.zip` + `name_WIDTHxHEIGHT.jpg` (the app names them for you).
Only animations you made yourself, please.
